
# VerifyFlow

Serverless KYC and Client Identity Verification Platform.

## Project Objective

VerifyFlow simplifies client onboarding by collecting identity
details, processing uploaded documents, extracting information,
identifying inconsistencies, and supporting human verification.

## Technology Stack

- Python
- React + Vite
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon S3
- AWS Step Functions
- AWS Textract
- AWS SAM

## Development Stages

### Stage 1
Minimum end-to-end serverless KYC workflow.

### Stage 2
Complete KYC/KYB platform with advanced verification,
authentication, auditing and security.

## Project Status

Initial development.
